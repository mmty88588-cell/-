# 个人博客项目 - 对话记录

## 日期
2026-05-15

## 需求概述
创建一个个人博客项目，具备以下核心功能：
- 用户注册
- 文章发布
- 分类管理
- 标签管理
- 评论系统
- 后台管理

## 技术栈
| 组件 | 选型 |
|---|---|
| 框架 | Spring Boot 2.7.18 |
| ORM | MyBatis (XML 映射) |
| 数据库 | MySQL 8.0 |
| 缓存 | Redis (Lettuce) |
| 分页 | PageHelper |
| 序列化 | Fastjson |
| 加密 | jBCrypt |

## 架构分层
```
Controller → Service → Mapper (XML)
     ↕           ↕

```

## Redis 缓存设计

| Key | 类型 | TTL | 说明 |
|---|---|---|---|
| session:{token} | String | 30min | 用户登录会话 |
| article:{id} | String | 10min | 单篇文章缓存 |
| article_list:{params} | String | 60s | 列表查询缓存 |
| hot_articles | ZSet | 永不过期 | 按浏览量排序 |

### 缓存策略
1. 文章列表优先从 Redis 读取，未命中则查 MySQL 并写入缓存
2. 每次阅读文章时 `ZINCRBY hot_articles 1 articleId`
3. 定时任务每5分钟将 ZSet 中的浏览量同步回 MySQL
4. 文章更新/删除时清除相关缓存

## 权限控制
- 公开接口无需登录
- LoginInterceptor 拦截 /api/**，从 Header 读取 `Authorization: Bearer <token>`
- AdminInterceptor 拦截 /api/admin/**，校验角色为 ADMIN
- 密码使用 BCrypt 加密

## 启动步骤
1. 执行 `schema.sql` 建库建表
2. 确保 MySQL (端口3306) 和 Redis (端口6379) 已启动
3. 修改 `application.yml` 中的数据库/Redis 连接信息
4. 运行 `mvn spring-boot:run`
5. 默认管理员账户: admin / admin123
